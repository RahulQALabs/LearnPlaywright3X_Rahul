# VS Code Shortcut Commands for JavaScript on Windows

This file contains useful VS Code shortcuts for JavaScript development on a Windows machine.

## 1. Basic File and Window Commands
- Ctrl + N -> New file
- Ctrl + S -> Save file
- Ctrl + Shift + S -> Save As
- Ctrl + P -> Quick open file
- Ctrl + Shift + P -> Open Command Palette
- Ctrl + W -> Close current editor
- Ctrl + Shift + W -> Close all editors
- Ctrl + F4 -> Close current tab

## 2. Editing Commands
- Ctrl + X -> Cut line / selected text
- Ctrl + C -> Copy line / selected text
- Ctrl + V -> Paste
- Ctrl + Z -> Undo
- Ctrl + Y -> Redo
- Ctrl + F -> Find
- Ctrl + H -> Replace
- Ctrl + D -> Add next occurrence to selection
- Ctrl + Shift + L -> Select all occurrences of current selection
- Ctrl + / -> Toggle line comment
- Shift + Alt + A -> Toggle block comment
- Shift + Alt + Down -> Copy line down
- Shift + Alt + Up -> Copy line up
- Shift + Delete -> Delete line
- Ctrl + Shift + K -> Delete line
- Tab -> Indent line
- Shift + Tab -> Outdent line

## 3. Navigation Commands
- Ctrl + G -> Go to line
- Ctrl + P -> Go to file quickly
- Ctrl + Shift + O -> Go to symbol
- F12 -> Go to definition
- Alt + F12 -> Peek definition
- Ctrl + Shift + F -> Search in files
- Ctrl + Shift + H -> Replace in files
- Ctrl + Shift + M -> Problems panel

## 4. Multi-Cursor and Selection Commands
- Alt + Click -> Add cursor
- Ctrl + Alt + Down -> Add cursor below
- Ctrl + Alt + Up -> Add cursor above
- Shift + Alt + Right -> Expand selection
- Shift + Alt + Left -> Shrink selection

## 5. Terminal Commands
- Ctrl + ` -> Open or close terminal
- Ctrl + Shift + ` -> Create new terminal
- Ctrl + Shift + C -> Open new terminal at current path

## 6. JavaScript / Node.js Related Commands
- F5 -> Start debugging
- Ctrl + Shift + D -> Open Run and Debug panel
- Ctrl + Shift + Y -> Open Debug Console
- Shift + Alt + F -> Format document
- Ctrl + Shift + P -> Run "Format Document"
- Ctrl + Shift + P -> Run "JavaScript: Go to Project Configuration"

## 7. Useful Extensions for JavaScript
- JavaScript (ES6) code snippets
- ESLint
- Prettier - Code formatter
- Live Server
- Debugger for Chrome
- Node.js Extension Pack

## 8. Quick Tips for JS Learning in VS Code
- Use Ctrl + P to quickly open JavaScript files
- Use Ctrl + / to comment code while practicing
- Use F12 to jump into function definitions
- Use Shift + Alt + F to keep code clean and readable
- Use Ctrl + Shift + P for any VS Code command quickly

## 9. Comments for JS Learning in VS Code
- Single Line Comment	Ctrl + /
- Multi-Line Comment	Shift + Alt + A
- Uncomment Single Line	Ctrl + /
- Uncomment Multi-Line	Shift + Alt + A
