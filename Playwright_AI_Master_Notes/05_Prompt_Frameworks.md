**Origin:** Adapted from behavioral interview technique

    ┌─────────────────────────────────────────────────────────┐
    │                    STAR FRAMEWORK                        │
    ├─────────────────────────────────────────────────────────┤
    │  S - Situation   │  Background and context              │
    │  T - Task        │  What needs to be done               │
